# 科研工作台前端

React、TypeScript与Vite构建本地实验界面。主要流程为自动仿真、人工疗程、技能审核、实验比较与导出；API和Worker说明见 [工作台文档](../docs/workbench/README.md)。

本文按 2026-11-10 的界面与服务契约核对。“进化试验”的业务操作受服务端开关控制，独立任务、版本和验证说明见 [试验文档](../docs/workbench/SKILL_EVOLUTION_EXPERIMENT.md)。

```powershell
npm --prefix frontend ci
npm --prefix frontend run dev
npm --prefix frontend test
npm --prefix frontend run lint
npm --prefix frontend run build
```

在项目根目录执行上述命令。开发页为 `http://127.0.0.1:5173`，`/api` 代理到 `http://127.0.0.1:8000`；批处理工作台入口使用 8001。生产静态包输出到 `src/psychsandbox/workbench/frontend_dist`，由 FastAPI 托管。修改界面后必须通过测试、lint 和含 TypeScript 检查的 build；仅改说明文档无需重建静态包。

请求携带服务端会谈版本和稳定操作ID；409冲突先同步权威版本，不为重试换一个ID。SSE使用真实任务通道和seq重放；切换案例或会谈时丢弃迟到请求。分数缺失显示未知，0显示0；勿用界面摘要推断临床结论。密钥只留后端环境，不写入前端资源。

自动实验台将配置、会谈回放和分析督导分栏展示；同一轮按咨询师发言、来访者回答的轨迹顺序回放，咨询师在左、来访者在右。会谈导航可横向滚动，日志、计划和评估摘要可折叠；窄屏通过「实验配置」「分析与督导」打开侧栏，按 Esc 可关闭。三栏固定在工作区内，实验配置使用紧凑间距，表单和启动按钮完整展示；历史运行列表独立滚动，较多的逐场轮数设置在局部列表中滚动。回放顺序及缺失回答由前端回归测试覆盖。

全局导航、会谈标题与场次切换使用紧凑布局，优先为聊天记录保留纵向空间。会谈区直接展示当前阶段、已提交场数，以及候选轮数或量表评估进度；无需展开任务与日志面板。多个实验可按案例与状态切换。进度使用后台持久快照和实时事件，刷新后恢复，并忽略旧执行尝试的迟到更新；停止、取消、失败与安全暂停分别显示。

桌面端可通过左栏标题旁的按钮折叠整列配置与历史记录，再由工作区左边缘的展开图标恢复；折叠保留表单草稿和当前运行。工作区使用较小的外边距与列间距，导航和控制文字适度放大，聊天正文字号略小以容纳更多记录。

数值框保留编辑中的空值和 0，提交时由表单检查必填、整数与范围。失败或已停止的历史运行显示「从会谈边界续跑」及恢复位置；续跑使用原案例、种子、总会谈数、轮数与 RFT 设置，与左侧新实验草稿独立，评分方法仍需通过后端兼容检查。

进度契约由 `src/types.ts`、`src/utils/progress.ts` 和 `SimulationProgress` 组件维护。任务查询返回当前 attempt 的最新持久快照，SSE 的 `simulation_status` 按 attempt/revision 合并；旧任务缺少快照时显示同步提示和已存会谈。提交进度只统计已落库场次；候选条标明“轮上限”，提前结束的成功疗程显示实际完成场数。相关回归位于 `tests/progress.test.ts`，回放与数值续跑测试分别在同目录维护。

病例接口返回 503 时显示后端修复说明，不把编译失败伪装成“没有案例”。真实浏览器中的宽度、滚动、侧栏折叠和重连仍需单独验收，单元测试不替代视觉检查。
