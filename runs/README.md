# 运行文件入口

- [tests/](tests/)：自动化测试，每次 `pytest` 都生成一个独立目录。
- [runtime/](runtime/)：实际仿真、数据下载和转换，每次命令生成一个独立目录。

目录按本机时间排序：`年月日-时分秒-微秒__用途或案例__唯一编号`。先看每次目录中的 `run.json`（状态、参数），测试看 `summary.txt`，仿真打开 `report.html`。续跑沿用原运行目录；普通重复运行生成新目录，不覆盖旧结果。

详细约定、清理方式（正式运行用 `runs delete`，测试日志用 `runs clean-tests`）和迁移说明见 [运行文件说明](../docs/RUN_ARTIFACTS.md)。只有这些说明文件纳入 Git；实际产物全部忽略，可能包含案例、对话和模型诊断内容。
