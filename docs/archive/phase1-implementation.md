# 阶段一实现与数据流历史基线

## 历史结论

原阶段记录说明五流派共享domain/datasets/agents/skills/runtime/evaluation边界，咨询师规划→目录→执行，来访者授权→规划→台词核验，以及会后记忆、自评和纵向计划。它不代表参数训练、技能自动晋升或临床验证已经完成。现行领域边界与评分接口已重写，不再把每场RFT报告存入正式SessionRecord。

## 阅读边界

这是原日期下的阶段证据，不将旧实验、建议或测试数改记为本次验证。当前说明以 [文档索引](../README.md) 为入口；新版本提供批量逐条目logprob、统一温度及评分方法兼容保护。技能审核、独立效果评估和权重训练不能从阶段性代码存在推断完成。

2026-11-10 阅读校正：`runtime/progress.py` 现在还定义仿真阶段并汇总候选与量表快照，终端绘制由 `console.py` 负责；工作台将快照持久化为事件。`datasets/progress.py` 独立记录转换阶段。下表的模块描述保留历史口径，当前职责见 [领域边界](../agents/domain.md)。

## 原统计与问题证据

| 模块 | 原阶段职责 | 当时的职责边界 |
|---|---|---|
| `domain/` | 5Ps、状态、计划、评测和轨迹等稳定契约 | API 调用和流程编排 |
| `datasets/` | 五流派原始案例转换和索引 | 技能选择 |
| `therapies/` | 流派、阶段目标、概念化焦点和量表映射 | 对话生成 |
| `agents/` | 来访者两阶段生成、咨询师 ReAct 与会后自评 | 持久化 |
| `skills/` | 技能注册、硬过滤、按 ID 展开和超量候选的向量筛选 | 最终适用判断或自动晋升 |
| `runtime/` | 会谈编排、候选隔离与选优、披露、安全、状态、记忆、计划和 SQLite | 训练基础模型 |
| `runtime/run_management.py` | 只读预览、按编号同步删除、失败日志与重试 | 自动监视目录或删除共享案例/技能 |
| `runtime/progress.py` | CLI 候选与评分进度条的标签、百分比图形和耗时文案 | 采集模型调用、评判分数或写入运行状态 |
| `evaluation/` | 每 session 量表评分、可选概率加权（logprob）评分与端点探测、规则安全门控、纵向、候选 RFT 评分和整体 PsychEval 评测 | 临床诊断或疗效判断 |
| `visualization/` | 从已保存结果渲染离线 HTML/SVG | 修改运行状态 |
