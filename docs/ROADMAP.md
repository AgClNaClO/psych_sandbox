# 实施与实验路线

## 第一阶段验收

1. 执行数据 fetch/convert，确认 manifest 为 148 个 CBT 案例。
2. 对 10 个案例、每个 3 个 seed 运行 3 sessions，保留配置、成本和失败原因。
3. 用 Mock 验证可复现控制流，再用至少一个真实兼容 API 完成契约测试。
4. 导出 WAI-lite、CTRS-lite、阶段/人设一致性、泄漏和安全六个独立维度。
5. 人工抽查咨询师输入载荷，确认没有完整画像或未解锁事实。
6. 形成均值、标准差、置信区间、失败案例与安全误报分析。

## 第二阶段

建立经心理学背景评审者复核的 EFT 独立技能库；实现 CBT、EFT、integrative
三个 `TherapyProfile`。比较“无督导反馈/有督导反馈”，并在轨迹中证明督导反馈
改变了下一次计划或技能候选。

## 第三阶段

只将安全与泄漏门槛通过的轨迹放入经验池。候选技能依次经历 candidate、
replayed、expert_reviewed、approved、promoted；不能自动晋升。先用 3B/4B
模型做 4-bit QLoRA SFT，再用 chosen/rejected 做 DPO 或 session 级拒绝采样微调。
任何关键指标回退都要恢复旧技能版本或模型。

## 推荐实验矩阵

- A：通用模型，无记忆、无技能。
- B：结构化记忆。
- C：记忆 + PsychEval 层级技能。
- D：记忆 + 技能 + 督导反馈。
- E：完整系统 + 披露控制 + 安全层。
- F：技能进化或参数训练后系统。

正式实验至少 30 个 CBT 案例；安全集至少 100 条；人工评审至少 30 个脱敏或
合成 sessions，由两名心理学背景评审者报告加权 Kappa。
