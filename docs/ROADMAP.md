# 后续实验与验收路线

代码能力和研究效果分开验收。当前系统具备五流派模拟、受限记忆、技能目录、可选会谈候选选优、整体督导和本地 Web 工作台；逐条目 logprob 为新的评分方法版本，不是临床效度提升的证明。

截至 2026-11-10，转换并发与结果复用、持久化网页进度、历史运行续跑和隔离技能进化试验已有实现。后续工作应基于这些能力设计实验，不能继续把对应入口列为未开发功能。

## 近期实验

1. 用固定病例、提示词及配置比较离散条目与 item_logprob_v2，分别报告失败率、质量门触发、分数与候选排名变化。
2. 分层覆盖五流派，至少多个 API 重复；记录供应商、模型、有效温度、截断和延迟，不能以本地 seed 宣称远端确定性。
3. 检查咨询师输入无私有画像，候选落选状态不进入记忆；人工核对引用、漏披露、过早披露和失败案例。
4. 正式研究再扩大至多案例多会谈，报告分项指标、区间和安全误报/漏报，不以总均值掩盖失败。
5. 对转换串行/并发、冷/热缓存分别记录真实端点耗时、调用数、限流和产物一致性。离线替身中的并发验证不作为线上加速倍数。
6. 利用独立技能试验固定上下文对比，并以相同案例、种子和配置运行两组新轨迹；人工复核来源证据、合并范围、退化案例和安全性。

## 机制比较

优先比较：基础对话、允许记忆、技能目录、自评/再规划、披露控制及 PatientAct。候选数、采样温度和评分口径单独控制。完整人格/情绪动力学、技能进化效果评估及参数训练属于独立后续研究，见 [研究索引](research/README.md)；已实现的技能提取入口见 [独立试验](workbench/SKILL_EVOLUTION_EXPERIMENT.md)。

外部评分保持独立，只用于评测或候选排序；若研究评分反馈驱动规划，须建立明确的另一个实验条件。工作台导出不等于已经完成 SFT/DPO 训练，更不代表论文模型复现。

## 完成证据

软件变更运行全套 pytest；前端变更另运行测试、lint 和 build。涉及模型或端点能力的实验另行执行小规模 probe，普通文档维护不需要真实 API 调用。研究验收需要独立复评、专家盲评和样本设计；历史通过数与单次探针不能替代这些证据。阶段基线见 [归档](archive/README.md)。
