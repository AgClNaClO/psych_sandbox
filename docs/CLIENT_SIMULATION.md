# 来访者模拟：授权事实与反应状态

当前病例契约为schema-v4，提示词版本为psycheval_patientact_v7。PsychEval提供事实及流派概念化，PatientAct启发互动策略；两者不混成新的病例真相。

实现核对：2026-11-10。生产病例由五流派 extractive 转换生成，抽取跳过无语义标点、保留有含义的短事实；加载器拒绝污染或过期缓存，不在仿真时自动重编译。转换并发和进度规则见 [运行产物](RUN_ARTIFACTS.md)。

## 每轮数据流

会前私有状态与咨询师话语 → 话题/依赖/会谈范围/信任门控 → 策略规划 → 受限台词生成 → 台词证据及提前披露核验 → 提交已说事实与状态。

发言器仅看到本轮授权原子、已说片段、表达指导和必要状态，不接收完整私有画像、blocked正文、规划rationale或信任方向。生成重试不重复提交状态；新信任下一轮才参与披露。RFT复制各候选起点，仅赢家进入会后记忆。

CLI 和网页中的候选轮数是执行遥测；多个候选各自更新私有分支状态，不能将轮数相加作为已提交会谈或跨场状态。网页刷新、重新连接或切换实验只恢复显示，不触发新的来访者响应。

## 策略、消融与状态

Compact默认一次规划加一次语言生成；Faithful先分别判断reaction/behavior，必要时额外判断resistance，接受台词后再判断信任，共两次前置规划、可选阻抗、一次生成和一次信任调用。Simple跳过状态规划，仍受披露/泄漏检查。

| 配置 | 关闭时的含义 |
|---|---|
| use_memory | 禁止新检索事实，仍保留已说证据；不退化为完整私有画像直喂 |
| use_pipeline | 去掉反应/行为规划，保留受限生成及台词核验 |
| use_trust_gating | 只绕过信任阈值；话题、依赖、范围与歧义规则仍生效 |

状态含效价、唤醒、痛苦、信任、阻抗、希望、疲劳与关系破裂。这些是工程仿真变量。情绪变化使用独立事件评价线索，不把目标进展直接等同情绪改善；痛苦和信任可以同时升高。会谈边界部分保留信任、恢复疲劳，未修复破裂继续存在。

显式ClientSimulationConfig是私有实验配置，记录来源、未知程度和版本，不自动从病例猜人格。uncertainty=1时调节为零；表达偏好影响最多0.1，威胁/恢复调整最多0.05，不改变披露阈值。依恋条件只有指定模式、来源事实可解析且confidence至少0.5时才进入规划，并只指导trust_change；生产编译默认unspecified。

## 话题与空转

默认tags匹配。可选semantic是本地字符一元/二元重叠近似（默认阈值0.4），不是嵌入语义或模型主题抽取，不能处理所有否定、跨语言和改述。

咨询师侧空转检查至少观察3轮，并在近期4轮中满足重复内容、连续simple_response、极简回应密度三项中的两项。触发后换方向或交接，原因留审计，不修改来访者披露权限。阈值是工程假设。
